How the methods work

Mutual exclusion: all entry nodes ask one elected coordinator, which serializes seat updates with a mutex.

Bully election: a node challenges higher IDs. The highest reachable node recovers replica state before announcing itself.

Replication: a reservation needs two durable copies before a success response. An interrupted response may have an uncertain outcome. Retry with the same request ID.

Lamport clocks: nodes increment their logical counters on local events and RPC receipt. Counters help explain event order, but do not measure elapsed time.
